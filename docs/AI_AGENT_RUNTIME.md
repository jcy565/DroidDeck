# Local AI agent integration checkpoint

GameAgent is a strict single-selected-file model-to-tool boundary, not a shipped LLM. It accepts a user instruction, selected extension and text, calls a local model adapter once, parses a flat JSON response and dispatches only known actions. INI/CFG proposals use existing-key numeric/boolean patch validation; TSV/CSV/flat JSON translation proposals are limited to five rows and cannot overwrite existing edits or change placeholders; log responses contain model advice plus separate deterministic evidence. No shell, path selection, original writes or automatic apply. Model cancellation is cooperative; runtime initialization, hard limits, isolated resource ownership and source revision recheck before UI draft commit remain required. All model text is untrusted. Single-window drafts need review; no game-wide discovery, automatic tests or autonomous repair implemented.

Runtime candidate: Google LiteRT-LM, official Kotlin Android API. Current DroidDeck toolchain is Kotlin 2.1.0 / AGP 8.8.0. Official LiteRT-LM docs state recent 0.17/0.18 versions use Kotlin 2.4 metadata and require compiler 2.3+; avoid silently upgrading existing build or suppressing metadata checks. Investigate a separately tested runtime module/toolchain, pinned supported model license/size and native cancellation; select a small multilingual instruction model with Korean and tool-format quality evaluated on hardware. Do not claim model integration until actual inference passes. References: https://developers.google.com/edge/litert-lm/android and https://github.com/google-ai-edge/LiteRT-LM/blob/main/docs/api/kotlin/getting_started.md .
