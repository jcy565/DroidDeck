# Local AI agent integration checkpoint

GameAgent is a strict single-selected-file model-to-tool boundary, not a shipped LLM. It accepts a user instruction, selected extension and text, calls a local model adapter once, parses a flat JSON response and dispatches only known actions. INI/CFG proposals use existing-key numeric/boolean patch validation; TSV/CSV/flat JSON translation proposals are limited to five rows and cannot overwrite existing edits or change placeholders; log responses contain model advice plus separate deterministic evidence. No shell, path selection, original writes or automatic apply. Model cancellation is cooperative; runtime initialization, hard limits, isolated resource ownership and source revision recheck before UI draft commit remain required. All model text is untrusted. Single-window drafts need review; no game-wide discovery, automatic tests or autonomous repair implemented.

Runtime candidate: Google LiteRT-LM, official Kotlin Android API. Current DroidDeck toolchain is Kotlin 2.1.0 / AGP 8.8.0. Official LiteRT-LM docs state recent 0.17/0.18 versions use Kotlin 2.4 metadata and require compiler 2.3+; avoid silently upgrading existing build or suppressing metadata checks. Investigate a separately tested runtime module/toolchain, pinned supported model license/size and native cancellation; select a small multilingual instruction model with Korean and tool-format quality evaluated on hardware. Do not claim model integration until actual inference passes. References: https://developers.google.com/edge/litert-lm/android and https://github.com/google-ai-edge/LiteRT-LM/blob/main/docs/api/kotlin/getting_started.md .

## Experimental MediaPipe model runtime connection

The optional `-PexperimentalLocalAi=true` Gradle property selects the localAi source directory and a pinned tasks-genai:0.10.35 dependency; default builds select noLocalAi and add no GenAI dependency. The adapter uses the documented MediaPipe Java LlmInference/LlmInferenceSession async inference API, CPU backend, 4096 context tokens and a reserved 1024 output tokens. No model is bundled. A user explicitly imports a trusted compatible .task file with a publisher-provided SHA-256 (max 1 GiB per model, 2 installed files) into app-private storage. Hash is checked at import and before inference. The experimental editor exposes natural-language requests for selected config/log/translation files and dispatches GameAgent results only to preview/draft/advice. Source revision, memory/session gates, single native owner, cancellation requests and no automatic original writes. A conservative 2 GiB available-memory floor is a heuristic, not measured. Native load, inference and cancellation/cleanup behavior are unverified; cancellation is not a guaranteed immediate resource release. If native completion stalls the lease remains occupied rather than destroying an active session. No runtime tests on actual device. MediaPipe is maintenance-mode and SDK metrics/privacy review is required. Existing tasks-vision 1.0.0 dependency may conflict with GenAI 0.10.35; resolve and test dependency/native compatibility before enabling for any user release. No assumption that a digest proves provenance or format compatibility. No download or model distribution. References: https://github.com/google-ai-edge/mediapipe/tree/v0.10.35/mediapipe/tasks/java/com/google/mediapipe/tasks/genai/llminference and https://ai.google.dev/gemma/docs/conversions/hf-to-mediapipe-task . No claim of real inference until run.
